═══════════════════════════════════════════════════════════════
  关键改进
═══════════════════════════════════════════════════════════════

✅ 输出端口水平排列
   - 所有偏移量在一行显示
   - 端口在方框底部
   - 居中对齐

✅ 树形扇开布局
   - 第一层子节点水平展开
   - 每层自动计算宽度
   - 子节点在其空间内居中

✅ 精确端口连接
   - 第 0 个输出端口 → 第 0 个子节点
   - 第 1 个输出端口 → 第 1 个子节点
   - 第 N 个输出端口 → 第 N 个子节点

✅ 优化的贝塞尔曲线
   - 先向下延伸
   - 再水平移动
   - 最后指向目标
   - 更清晰的视觉流


═══════════════════════════════════════════════════════════════
  布局参数
═══════════════════════════════════════════════════════════════

节点尺寸：
  - 宽度: 320px (普通) / 280px (紧凑)
  - 高度: 自动调整

端口尺寸：
  - 输入端口: 6px 半径，蓝色 (80, 140, 200)
  - 输出端口: 6px 半径，绿色 (90, 190, 90)

偏移量方框：
  - 宽度: 55px
  - 高度: 32px
  - 间距: 8px
  - 绿色背景

间距设置：
  - 水平间距: 150px (普通) / 100px (紧凑)
  - 垂直间距: 200px (层级之间)
  - 方框间距: 8px


═══════════════════════════════════════════════════════════════
  使用示例
═══════════════════════════════════════════════════════════════

// 创建根节点
PointerChainNode* root = new PointerChainNode("BaseAddress", 0x140000000);
root->AddOffset(0);      // 输出端口 0
root->AddOffset(8);      // 输出端口 1
root->AddOffset(16);     // 输出端口 2

// 添加子节点（对应输出端口）
PointerChainNode* child0 = root->AddChild("分支A", 0x10000000);  // 连接到端口 0
PointerChainNode* child1 = root->AddChild("分支B", 0x20000000);  // 连接到端口 1
PointerChainNode* child2 = root->AddChild("分支C", 0x30000000);  // 连接到端口 2

// 继续添加更深层级
child0->AddOffset(16);
child0->AddOffset(32);

PointerChainNode* child0_0 = child0->AddChild("A-1", 0x11000000);  // 连接到 child0 的端口 0
PointerChainNode* child0_1 = child0->AddChild("A-2", 0x12000000);  // 连接到 child0 的端口 1

// 设置根节点（自动树形布局）
tree.SetRoot(root);

═══════════════════════════════════════════════════════════════
  视觉效果
═══════════════════════════════════════════════════════════════

端口连接关系：
  根节点有 3 个输出端口：
    端口 0 (偏移 0)  ─────→ 子节点 0 (分支A)
    端口 1 (偏移 8)  ─────→ 子节点 1 (分支B)
    端口 2 (偏移 16) ─────→ 子节点 2 (分支C)

贝塞尔曲线路径：
  起点 → 向下延伸 → 水平移动 → 向下延伸 → 终点
  
颜色方案：
  - 根节点: 深蓝色 (38, 64, 89)
  - 子节点: 灰蓝色 (46, 56, 71)
  - 选中: 金色边框 (255, 204, 51)
  - 连接线: 青绿色 (80, 180, 140)
